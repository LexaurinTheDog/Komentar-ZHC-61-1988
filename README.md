# Komentář k zákonu č. 61/1988 Sb., o hornické činnosti, výbušninách a o státní báňské správě

Otevřený komentář k zákonu o hornické činnosti, výbušninách a o státní báňské správě — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; hornická činnost a činnost prováděná hornickým způsobem, báňská záchranná služba, povolování hornické činnosti, nakládání s výbušninami, podzemní objekty, Český báňský úřad a obvodní báňské úřady, přestupky.

Konsolidované znění: dokument e-Sbírky `SB-1988-00061_2026-01-01`.
